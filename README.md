# TypeScript Playground · Fundación Luckia

Playground para practicar TypeScript en el curso **Front End Moderno y Herramientas IA** de Lemoncode, en colaboración con Fundación Luckia.

## Primeros pasos

```bash
npm install
npm start
```

Abre [http://localhost:3001](http://localhost:3001) y después la consola del navegador (<kbd>F12</kbd>).

Escribe tu código en `src/playground.ts`. Se transpila al guardar y la página se recarga automáticamente.

## Scripts

| Script              | Descripción                                               |
| ------------------- | --------------------------------------------------------- |
| `npm start`         | Transpila en modo observación y arranca el servidor local |
| `npm run transpile` | Transpila `src/` en `dist/`                               |
| `npm run copy`      | Copia los archivos HTML, CSS y SVG de `src/` a `dist/`    |
